# Glenn Velasco contact card

Live page: https://glenn-the-great.github.io/card/

## To edit the text
To edit: open github.com/glenn-the-great/card, click index.html, click the pencil icon, change the text, click Commit changes. The live page updates in about a minute.

The comment at the top of index.html shows where the name, title, phone, email, and address are. If the phone or email changes, also edit glenn-velasco.vcf (the "Save contact" file) the same way.

## To upload a photo
Open github.com/glenn-the-great/card, click Add file, then Upload files. Drag the photo in and click Commit changes. Then ask Grok Bot to place it on the page.
